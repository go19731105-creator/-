# はじめての飛行機 乗り方ガイド（動画）

飛行機に乗ったことがない人向けに、空港に着いてから目的地に到着するまでの流れを
イラスト・字幕・ナレーションで説明する動画です。

- 動画: [`airplane_boarding_guide.mp4`](airplane_boarding_guide.mp4)（1280×720 / 約5分40秒 / ナレーション＋BGM・ステレオ音声）

## 内容

| STEP | 内容 |
| --- | --- |
| 1 | 出発前の準備（便名・時刻の確認、パスポート、空港に着く時間の目安） |
| 2 | チェックイン（カウンター・自動チェックイン機・オンライン、搭乗券の見方） |
| 3 | 荷物を預ける（モバイルバッテリー・ライターは手荷物へ、貴重品・薬は手元に） |
| 4 | 保安検査（トレー、金属探知機、国際線の液体ルール、持ち込めない物、出国審査） |
| 5 | 搭乗ゲートへ（ゲート到着時刻の目安、ゲート変更、QRコードで搭乗） |
| 6 | 座席に着く（座席番号の読み方、荷物の置き場所、シートベルト） |
| 7 | 離陸の前に（機内モード、背もたれ・テーブル、安全のビデオ） |
| 8 | 飛行中（ベルトサイン、飲み物、耳が痛いとき、呼び出しボタン） |
| 9 | 到着（着席して待つ、忘れ物チェック、荷物の受け取り、入国審査・税関） |

※ 時間や持ち込みのルールは航空会社・路線・空港によって異なります。実際に利用する航空会社の案内を確認してください。

## 動画の作り直し方

台本（字幕・ナレーション・ポイント）は `make_video.py` の `SCENES` にまとまっています。
編集したあと、次のコマンドで動画を再生成できます。

```sh
pip install pillow numpy pyopenjtalk
python3 video/make_video.py            # video/airplane_boarding_guide.mp4 を出力
```

必要なもの: Python 3、ffmpeg、IPAゴシックフォント（`fonts-ipafont-gothic`）。
ナレーションは Open JTalk（pyopenjtalk）による音声合成、BGMはスクリプト内で合成しています（話している間は自動で小さくなります）。

# TENNIS ch.249（テニスチャンネル）宣伝動画（テニススクール生徒募集つき）

福山市沖野上町のテニスショップ「TENNIS ch.249（テニスチャンネル）」を紹介し、
テニススクールの生徒募集（見学・体験）を案内する宣伝動画です。

- 動画: [`tennis_channel_promo.mp4`](tennis_channel_promo.mp4)（1280×720 / 約1分35秒 / ナレーション＋BGM＋効果音・ステレオ音声）

| シーン | 内容 |
| --- | --- |
| オープニング | コートでのラリーと店名「TENNIS ch.249」 |
| テニス好きが集まるお店 | 大画面でプロの試合を観戦／コーヒー片手にのんびり |
| ラケット・ガットのことなら | YONEX・Babolat中心のラケット新品注文／ガットの張り替え／道具選びの相談 |
| お知らせ | TENNIS ch.249 テニススクール 生徒募集中！ 見学・体験 お気軽に |
| はじめてでも安心！ | はじめての方も大歓迎／子どもから大人まで／道具の相談もお店で |
| お問い合わせの流れ | LINEで連絡 → 動きやすい服と運動靴で → コーチと一緒に打ってみる |
| エンディング | 住所・電話番号と「ご来店・お問い合わせは事前にLINEで」 |

店名・住所・電話番号は `make_tennis_promo.py` 冒頭の `SHOP_NAME` / `ADDRESS` / `TEL` など、
台本（字幕・ナレーション・画面の文字）は `SCENES` で変えられます。
スクールの内容（対象・曜日・料金など）は実際に合わせて書き足してください。

```sh
pip install pillow numpy pyopenjtalk
python3 video/make_tennis_promo.py      # video/tennis_channel_promo.mp4 を出力
```
