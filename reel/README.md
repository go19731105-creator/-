- 動画: [`beauty_reel.mp4`](beauty_reel.mp4)（縦 1080×1920 / 約16秒 / BGM・効果音入り）
- カバー画像: [`cover.png`](cover.png)

## 投稿するときのポイント

1. **音源はアプリ内で人気の音源に差し替えるとおすすめに載りやすくなります。** 動画にもBGMは入っていますが、リール編集画面で「音源」から流行中の曲を選び、元の音声の音量を下げてください。
2. **カバーは `cover.png` を設定**（プロフィール一覧で3:4に切り取られても文字が収まる配置です）。
3. **位置情報に「福山市」またはサロンの住所を追加**すると、近くのユーザーに表示されやすくなります。
4. **投稿後1時間はコメントにすぐ返信**しましょう。DMの「相談」には、メニュー紹介と空き状況をテンプレで返すとスムーズです。
5. **ストーリーズでもシェア**し、「保存してね」スタンプや質問箱（「お肌の悩み教えて」）を添えると反応が増えます。
6. 同じ型（「福山で〇〇な人がやってる3つのこと」）で、まつげ・ネイル・脱毛・ヘアなどメニュー別にシリーズ化すると、フォローする理由が強くなります。

## 実際のサロン映像に差し替えるなら（さらに効果アップ）

文字だけの動画より、実際の施術や店内の映像のほうが信頼感が出て予約につながりやすくなります。スマホで縦向きに撮った次の素材があれば、同じ台本のまま背景を差し替えられます。

| シーン | 撮るもの（各3秒前後） |
| --- | --- |
| フック | 施術後のツヤ肌・仕上がりのアップ、または鏡を見て笑顔になるお客様（許可を取って） |
| 01〜02 | 手でやさしく押さえる洗顔・保湿の手元アップ |
| 03 | 施術中の手元、施術ベッド・店内 |
| サロン紹介 | 外観・入口・看板、スタッフが手を振る |
| CTA | スタッフが画面に向かって「フォローしてね」 |

## 動画の作り直し方

文言・色・サロン名は `make_reel.py` の先頭（`SALON`, `AREA`, `SCENES` と各 `scene_*` 関数）にまとまっています。編集後、次のコマンドで再生成できます。

```sh
pip install pillow numpy
python3 reel/make_reel.py        # reel/beauty_reel.mp4 と reel/cover.png を出力
```

必要なもの: Python 3、ffmpeg、IPAゴシックフォント（`fonts-ipafont-gothic`）。
